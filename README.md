# 📔 About 📔
This project is built on Godot 4.6.1. You can find and install this version from their [archives](https://godotengine.org/download/archive/) page.

This project is currently a Work In Progress (WIP). 

The goal for contributers of this project is to get everyone started learning the basics of Game Development, navigating Godot's Game Engine, developing proficiency in GDScript and C#, and working under team collaboration on GitHub. This project is beginner friendly and should cover the basics of scripting, game objects/prefabs, basic collisions, and more.

## 🗺️ Project Plans and Goals

- Recreate a traditional platformer game in Godot. (Movement System, Coin/Upgrade System, Good Game Feeling)
- Develop a plot and world. (Hockey Paddle with expanded freedom of movement, Ball physics update, smaller goal hitboxes, Visual Overhaul to match Air Hockey Aesthetic)
- Add any additional mechanics related to said plot and level design.
- Add Music and Sound Effects.
- Have a functional menu and level navigation system
